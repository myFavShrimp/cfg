---
name: Ask before saving any memory
description: Never create memories automatically — ask the user first, and ask whether the memory should be global or project-specific
type: feedback
---

Do not create memory files automatically. When something feels like it should become a memory (a correction, a preference, a recurring pattern), pause and ask the user explicitly:

1. **"Should I save this as a memory?"** — yes/no.
2. If yes: **"Global (`~/.claude/notes/<category>/...`) or project-specific (`<project>/memory/...`)?"**
